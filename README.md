# Nova Habitat — Démo immobilière

**Nova Habitat** est un **projet conceptuel de site immobilier moderne et responsive**, réalisé pour démontrer des compétences en conception d’interface, structuration de contenu, responsive design et développement web front-end.

> **Important :** Nova Habitat est une démonstration fictive créée à des fins de portfolio. Ce projet ne représente pas un client réel, une agence immobilière existante ni une collaboration commerciale.

## Démo en ligne

https://abeditiemoko.com/demos/nova-habitat/

## Objectifs du projet

Le projet illustre une présence digitale professionnelle pour une activité immobilière, avec une attention particulière portée à :

- la lisibilité des offres ;
- la présentation visuelle des biens ;
- la navigation sur ordinateur et mobile ;
- la hiérarchisation de l’information ;
- l’expérience utilisateur et les appels à l’action.

## Technologies

- HTML5
- CSS3
- JavaScript
- Responsive Design
